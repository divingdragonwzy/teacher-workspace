# 拾题 初中英语题库

第一阶段产品源码备份，保存于 2026-10-08。

## 下载与运行

下载并解压本仓库的 `teacher-workspace-source-2026-10-08.zip`，进入其中的 `teacher-workspace` 文件夹。安装 Node.js 22.13 或以上版本后运行：

```powershell
npm install
node scripts/local-setup.mjs
node scripts/run-framework.mjs dev --host 127.0.0.1
```

打开终端显示的本地地址（默认 http://127.0.0.1:5173）。详细功能、测试方法和使用限制见压缩包内的 README.md 和使用说明.md。

## 已实现

- 初中英语 Word（.docx）试卷导入、题目与答案提取、人工核对入库。
- 按年级、知识点、题型筛选题目和组卷。
- 完形填空、阅读等共用材料题整题选入，小题重新从 1 编号。
- 共用插图插在材料对应位置，不显示额外配图标记。
- 学生卷与教师答案导出；小题不单独标分，短选项同行排列。

## 备份范围

这里只保存源码、测试及说明，不包含 node_modules、原始试卷、上传图片、本地题库、导出试卷、密钥、账号凭据或原部署项目标识。压缩包是完整源文件备份，不是逐文件 Git 提交，也不是业务数据备份。首次启动不会自动恢复原电脑上的题库。

这是本地版源码备份，不代表系统已上线。不要把本地模拟登录服务暴露到公网。规则解析仍需教师核对；正式打印前请在 Word/WPS 中确认实际分页。
